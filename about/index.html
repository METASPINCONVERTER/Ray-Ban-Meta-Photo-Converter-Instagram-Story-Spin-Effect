About MetaSpin

A zero-server, privacy-focused image formatting utility designed to make the Instagram 3D Spin View effect accessible to every creator.

Published by MetaSpin Engineering • Updated March 2026 • Open Web Project

Our Mission

When Meta Platforms and EssilorLuxottica launched the Ray-Ban Meta Smart Glasses, they introduced an innovative mobile feature: when smart-glasses photos are imported into an Instagram Story, an on-device depth estimation model generates a dynamic 2.5D parallax mesh that animates whenever the viewer tilts their smartphone.

However, this compelling visual capability was strictly gatekept by hardware: Instagram only displays the 3D Spin icon if the JPEG file matches the precise 3:4 portrait aspect ratio (3024 × 4032) and contains specific hardware-level EXIF tags.

MetaSpin was created to democratize this feature. We provide an instant, elegant, and 100% free web utility that lets photographers, content creators, and casual users reformat any image to meet Instagram's exact hardware profile.

The Zero-Upload Privacy Architecture

Most online image conversion services upload your photos to remote cloud servers to perform processing. We believe personal photography should remain completely private.

100% In-Browser Execution

MetaSpin performs all image decoding, aspect ratio calculation, canvas rasterization, and binary JPEG EXIF segment reconstruction directly inside your browser via HTML5 Canvas and native Web APIs. Not a single byte of your photo ever touches an external server.

Core Technical Capabilities

  • Accurate 3:4 Portrait Framing: Automatic orientation correction and cover-crop rendering to native 3024 × 4032 pixels.
  • Standardized Metadata Injection: Splices compliant Make: Meta AI and Model: Ray-Ban Meta Smart Glasses 2 tags into the JPEG APP1 block.
  • sRGB Color Profile Verification: Sets EXIF tag 0xA001 to 1 (sRGB) for optimal Instagram rendering.
  • GPS Coordinate Stripping: Erases location metadata to protect personal privacy when posting publicly.
